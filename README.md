# 坦克大战 · Tank Battle

一个用**纯 HTML5 Canvas + 原生 JavaScript** 写的经典坦克大战（Battle City 风格）游戏。无框架、无构建、无任何外部资源，双击 `index.html` 即可玩，也支持手机触屏。

## 在线试玩

👉 **https://xiong3clay.github.io/tank-battle/**

手机扫码或直接打开上面的网址即可，无需安装。

## 双人对战（联网）

两台设备打开同一个网址就能对战，不需要注册账号、不需要服务器。

1. 一方点击右上角 **双人对战** → 输入 6 位房间号 → **开房间**
2. 另一方点 **双人对战** → 输入同一个房间号 → **加入房间**
3. 双方各 **3 条命**，被对方击毁一次就扣 1 命并**立刻更换新地图**，双方满血复位继续
4. 一方 3 命耗尽即分胜负，按 R 可重新开始

> 联机走 WebRTC P2P（PeerJS 公共信令），只有开局握手经过公共服务器，之后画面数据在两端直连。
> 断线会被 8 秒心跳检测到，界面显示「对手已断开」，可以重新开房。

## 玩法

- 驾驶绿色坦克，守住屏幕底部中央的**基地（金色徽章）**。
- 每关敌人从顶部刷出，**全部消灭**即过关；连过 **5 关**即通关胜利。
- **基地被击中**或**生命耗尽**则游戏失败。
- 地形：橙色**砖墙**可被子弹打穿，灰色**钢墙**不可摧毁。基地上方只有砖墙保护，敌人靠近基地时基地会**闪烁告警**，记得回防。
- 数值：3 条命；被击中后原地重生并获得 **2 秒无敌**（坦克闪烁）；击毁敌人 +100 分，通关额外 +500 分。
- **道具**：击毁敌人有 20% 概率掉落，碰到即生效——护盾（5 秒无敌）、加速（8 秒移速 +30%）、补给（生命 +1，上限 5），HUD 底部显示剩余时间；道具 12 秒未拾取会淡出消失，同屏最多 6 个。
- **难度递增**：第 3 关起敌人刷新更快，第 4 关起敌人子弹更快；敌人会追踪同行/同列的玩家，靠基地时会优先扑向基地。
- **最高分**：历史最好成绩自动保存在浏览器本地，HUD 与结算界面都会显示。
- **音效**：开火 / 爆炸 / 被击中 / 过关均为 WebAudio 实时合成，可在游戏中随时静音。

## 操作

**桌面端**

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| `空格` / `J` | 开火 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始（结束或通关后） |
| `M` | 音效开 / 关 |

**手机 / 平板**

- 左下角**摇杆**：拖动控制方向
- 右下角**开火**：按住连发
- 右上角**暂停 / 重开**

## 技术说明

- 单人模式仅 3 个文件：`index.html`、`style.css`、`game.js`，**零外部资源**（无 CDN、无图片、无字体、无音频文件）。
- 双人对战额外两个本地文件：`net.js`（P2P 传输层，暴露 `window.Net`）与 `vendor/peerjs.min.js`（93KB，随仓库分发，不走 CDN）。
- Canvas 2D + `requestAnimationFrame` + `deltaTime` 主循环，逻辑分辨率 800×600。
- 音效由 WebAudio `OscillatorNode` / `BufferSource` 实时合成，**不使用任何音频文件**；`localStorage` 保存最高分。
- 按 `devicePixelRatio` 设置画布后备存储，高清屏不模糊；横竖屏等比缩放，不变形不裁切。
- 触屏用 **Pointer Events + `setPointerCapture`**，支持多指（一手移动、一手开火）；适配 iOS 安全区，禁止滚动 / 双击缩放 / 长按选中。
- 桌面与手机共用同一套输入抽象层，玩法逻辑完全一致。

## 自建服务器（把自己的电脑当服务器）

除了公共云和离线配对，还可以让**自己的电脑**当服务器，零依赖（只需要 Node）。

**方式一：局域网（同一 WiFi）**

双击 `server\start-lan.bat`，它会打印 `http://<你的内网IP>:8000/`。
同一 WiFi 下的设备打开这个地址，大厅里选「自建服务器」→ 输房间号 → 开房/加入。
（首次启动 Windows 会弹防火墙提示，需要允许。）

**方式二：公网（异地也能玩）**

双击 `server\start-tunnel.bat`：首次会自动下载 cloudflared（约 40MB），
然后打印一个 `https://xxx.trycloudflare.com` 地址。双方都打开这个地址即可，
页面会自动检测到「本页由自建服务器提供」并填好服务器地址。

说明：
- 电脑必须开着且不能睡眠，关掉窗口服务就停了
- 中继流量很小：输入 30Hz + 快照 20Hz，每对玩家 < 10KB/s
- `trycloudflare` 的地址每次启动都会变，重启后重新发一次
- 服务器只做静态文件 + 房间配对 + 转发，不做鉴权（小范围娱乐用）
