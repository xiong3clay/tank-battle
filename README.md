# 坦克大战 · Tank Battle

一个用纯 HTML5 Canvas + JavaScript 编写的经典坦克大战（Battle City 风格）游戏，单文件即开即玩，无需任何依赖或构建工具。

## 玩法

- 驾驶绿色坦克，守住屏幕下方的**基地（鹰徽）**，消灭所有红色敌军坦克即可过关。
- 敌军会不断从顶部刷新，并向你移动、开火。基地被击毁则游戏失败。
- 击毁**红色砖墙**有几率掉落道具：
  - ⭐ **星星**：提升火力
  - 🛡 **护盾**：短暂无敌
  - ♥ **生命**：增加一条命
  - 💥 **炸弹**：消灭场上所有敌军
- 关卡会逐渐变难：敌军更多、更快，还会出现需要两发子弹才能击毁的重型坦克。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| `空格` / `J` | 发射 |
| `P` | 暂停 |
| `回车` | 开始 / 继续 |

移动端会自动显示触屏虚拟按键。

## 运行

直接用浏览器打开 `index.html` 即可，或部署到任意静态托管服务（GitHub Pages、Vercel、Netlify 等）。

### GitHub Pages 部署

1. 打开本仓库的 **Settings → Pages**；
2. 在 **Source** 中选择 `main` 分支、根目录 `/ (root)`；
3. 保存后稍等片刻，即可通过 `https://<你的用户名>.github.io/<仓库名>/` 访问。

## 技术说明

- 纯原生 JavaScript，无框架、无外部资源。
- 13 × 13 瓦片地图，支持砖墙（可破坏）、钢墙、水面、草丛四种地形。
- 使用 Web Audio API 合成音效，Canvas 渲染粒子爆炸效果。
- 响应式布局，适配桌面与移动端。
